# Kitch chat merger

**See Twitch and Kick chat together when a streamer multistreams.**

Kitch chat merger is a browser extension for Chrome and other Chromium-based browsers (Edge, Brave, Opera). When you watch a streamer who is live on both Twitch and Kick at the same time, it shows the chat from the other platform right next to the chat you're already watching, so you see the whole community in one place.

## Features

- **Twitch + Kick in one chat**: messages from the other platform appear alongside the native chat in real time, marked with `[Twitch]` or `[Kick]` and with usernames in their original colors.
- **Automatic pairing**: when you open a verified streamer who has a verified account with the same name on the other platform, the pair is added for you.
- Works on regular channel pages and on pop-out chat.
- **Display modes**: inside the native chat, or in a small separate panel.
- **Emotes**: Kick emotes are shown as images on Twitch. Twitch emotes are shown as images in the panel and as their names inside Kick's chat.
- No account or login needed. Chat is read-only and anonymous.
- Nothing runs on pages other than Twitch and Kick.

## Running from source

There's no build step: the repository is the unpacked extension.

1. Get the code:

   ```sh
   git clone https://github.com/factuall/Kitch-chat-merger.git
   ```

   or download it as a ZIP from GitHub (**Code → Download ZIP**) and extract it.

2. Open the extensions page in your browser:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
   - Opera: `opera://extensions`
3. Turn on **Developer mode** (toggle in the top-right corner, or in the left sidebar on Edge).
4. Click **Load unpacked** and select the cloned folder (the one that contains `manifest.json`).
5. Pin the extension from the puzzle-piece menu so the popup is easy to reach.

### Updating

Pull the latest changes (`git pull`), then click the reload icon on the extension's card in the extensions page and refresh any open Twitch/Kick tabs.

### Making changes

- After editing files, reload the extension on the extensions page and refresh the Twitch/Kick tab. Changes to `popup/` take effect the next time the popup is opened.
- Logs from the service worker (`src/background.js`) are under **Inspect views: service worker** on the extension's card; content-script logs are in the Twitch/Kick tab's DevTools console.
- For more verbose logging, set `DEBUG = true` in `src/background.js`, `src/kick-chat.js` or `src/kick-page-hook.js`. With the page hook in debug mode, run `__mcmDebug()` in the kick.com tab console.

## Usage

1. Click the extension icon and add a pair: the streamer's Twitch name and their Kick name. You can also paste a channel link.
2. Watch the stream on either platform as usual.
3. Messages from the other platform show up in the chat.

If messages stop appearing inside the chat (Twitch and Kick change their sites from time to time), switch the display mode to **Separate panel** in the popup.

Chat is read-only: you can read the other platform's chat but can't send messages to it.

## How it works

- **Twitch chat**: anonymous read-only IRC over WebSocket (`wss://irc-ws.chat.twitch.tv`).
- **Kick chat**: Kick hands out realtime connection info dynamically via `web.kick.com/api/v1/realtime/channels/<channelId>/chat/connection` (Pusher or Centrifugo; currently Centrifugo). Messages arrive on `chatrooms.<chatroomId>.v2`. Channel and chatroom IDs come from `kick.com/api/v2/channels/<slug>` and are cached. Kick's chat server only accepts connections from kick.com, so a `declarativeNetRequest` rule sets the `Origin` header on that WebSocket when you're watching on Twitch.
- **Showing messages on Twitch**: injected into Twitch's chat list.
- **Showing messages on Kick**: Kick's chat is a virtualized list, so a page script (`src/kick-page-hook.js`) hands messages to Kick's own chat renderer by replaying them on Kick's realtime socket in the same format as real messages. If that isn't available, a floating panel is used.
- **Auto-pairing**: Twitch verification = Partner status (Twitch GraphQL, the same public client ID twitch.tv uses); Kick verification = `verified` field of the channel API. Each channel is checked at most once a week; a pair the user removed is never re-added.

## Project structure

| Path | Purpose |
|---|---|
| `manifest.json` | Extension manifest (MV3) |
| `icons/` | Extension icons (generated by `tools/make_icons.py`) |
| `popup/` | Settings popup |
| `src/background.js` | Service worker: Kick/Twitch API calls, auto-pairing, Origin header rule |
| `src/twitch-chat.js`, `src/kick-chat.js` | Chat clients |
| `src/display.js` | Rendering into the page (native chat selectors live here) |
| `src/kick-page-hook.js`, `src/kick-native.js` | Native message injection on kick.com |
| `src/content.js` | Channel detection and session management |
| `src/shared.js`, `src/content.css` | Shared helpers and styles for content scripts |
| `tools/` | Development scripts, not part of the extension package |
